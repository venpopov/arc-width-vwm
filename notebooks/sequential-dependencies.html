Sequential dependencies

library(tidyverse)
library(bmm)

NotePrerequisites

This notebook tests empirical predictions of the RL algorithms developed in RL Algorithms: Exploration. The arc-width task and optimality framework are introduced in Optimal Arc Width (SDM).

Raw sequential dependencies

We saw that some reinforcement learning algorithms can find the optimal reward point. They do this by generally contracting the arc if the previous trial was a hit, and expanding it if it was a miss. Do we see this in the data? We know there are some sequential dependencies, although they are of a different kind.

exp1 <- read.csv("output/exp1_data.csv")
dat <- exp1 |> 
  select(subject, experimentorder,blocknumber,trialnumber,setsize,resperr,arc,points) |> 
  group_by(subject, experimentorder, blocknumber) |> 
  mutate(prior_arc = shift_vector(arc, by = 1),
         prior_resperr = shift_vector(resperr, by = 1))

dat |> 
  ggplot(aes(prior_arc, arc)) + 
  stat_summary(size = 0.1) +
  geom_abline(slope = 1)

This might be because we are collapsing over participants - even if there is no sequential dependency within participants, the above plot might show one if participants have much different average arcs. We can standardize the arc responses within participants to account for this. For each arc we get its percentile rank such that 0 represents the smallest arc within participant, and 1 represents the highest. We see that there is still sequential dependencies, although a big part of it was accounted for due to between-subject variability.

dat |> 
  group_by(subject, experimentorder) |> 
  mutate(arcp = ecdf(arc)(arc),
         arcp = round(arcp, 2)) |> 
  group_by(subject, experimentorder, blocknumber) |> 
  mutate(prior_arcp = shift_vector(arcp, by = 1)) |> 
  ggplot(aes(prior_arcp, arcp)) + 
  stat_summary(size = 0.1) +
  geom_abline(slope = 1)

The lag 1 correlation, computed within participants, has the following distribution:

dat |> 
  group_by(subject, experimentorder) |> 
  summarize(r = cor(arc, prior_arc, use = "pairwise.complete.obs")) |> 
  pluck("r") |> 
  hist(xlab = "Lag 1 correlation", main = "")

Contraction vs expansion

The above analyses do not tell us whether participants adapt their for the next trial depending on whether it currently contained the target or not. To see this, we want to measure the proportion of expanding vs contracting arcs conditional on whether the previous trial was a hit or not. For a single metric, we can calculate the likelihood ratio of expanding vs contracting conditional on hit or not

\[ \frac{Pr(a_{n+1} > a_n \,|\, a_n \geq abs(y_n))}{Pr(a_{n+1} \leq a_n \,|\, a_n \geq abs(y_n))} \]

smry1 <- exp1 |> 
  group_by(subject, experimentorder) |> 
  calculate_expand_likelihood_ratio()

smry1 |> 
  plot_likelihood_ratio()

Each point is a single subject, and each subject has as point for hits and a point after misses. First, we see that the likelihood ratio is much more variable after a miss. This is partly due to the low level of misses overall. We see a tendency for contraction after hits (likelihood ratio < 1) and tendency for expansion after misses (likelihood ratio > 1). This is supported by one sample t-tests:

t.test(filter(smry1, resp_type == "hit")$likelihood_ratio_expand, mu = 1, alternative = "less")

The experiment uses an interleaved design where the set size varies on each trial. Since arc responses vary strongly with set-size, what we are interested in is how their response changes not only from the previous trial but from what it would have been given the set size that they see. We can check if we compare the change direction with the previous time they encountered the same set size, depending on that previous time was a hit or miss. There can be any number of intervening trials and we only care about the last time that the same setsize occurred. We get a similar dependency:

smry2 <- exp1 |> 
  filter(exp_type == "SetS") |>

The graph and stats look like before but they tell us something different - people remember what arc they gave the previous time they encountered a given setsize and whether they hit or missed. When they encounter the same setsize condition, they tend to expand their arc relative to the one they gave to the previous trial of the same set size, not just the immediately previous trial, specifically if they missed last time with that set size.

So from the two analyses combined we know that people adapt their arc (expand or contract) based on at least two sources of information - the immediately preceding trial, and the last trial that had the same setsize condition.

Is it regression to the mean?

Klaus wrote:

I wonder how much this effect is due to regression to the mean: Once people settle on an approximately optimal arc width for each experimental condition, random deviations from it towards the narrower end are likely to produce a miss, and deviations to the wider end are likely to produce a hit. The next time the same condition comes around, random deviations towards the narrower end on the last trial of that condition are likely to now be followed by expansions, and vice versa. One way to gauge how much that contributes to the effect could be to shuffle the order of trials.

This is fair, so let’s test it. The potential confound applies not only to the long-range set-size dependency, but also to the original immediate trial dependency.

Check simulated data

First, let’s support that intuition by simulating some data which has to no adaptive arc change but only samples from a distribution. Then we can apply the analysis above to see if we see expansion after misses and contraction after hits as a confound of regression to the mean.

I will simulate data for response errors from the sdm:

\[ y \sim \text{sdm}(c = 4, \kappa = 3.5) \]

and arcs from a gamma distribution:

\[ a \sim \text{Gamma}(\alpha = 3, \lambda = 2) \]

library(bmm)
simulate_data <- function(n) {
  data.frame(
    resperr = rsdm(n, c = 4, kappa = 3.5),
    arc = rgamma(n, shape = 3, rate = 2)
  ) |> 
    calculate_expand_likelihood_ratio()
}

replicates <- 1000
trials <- 1000
out <- replicate(replicates, simulate_data(trials), simplify = FALSE)
out <- do.call(rbind, out)
out |> 
  plot_likelihood_ratio()

So Klaus is correct in principle - this simulated data had response error and arc width sampled independently and shows an almost identical effect as with the real data. Thus this finding alone does not indicate real adaptive expansion or contraction in response to hits / misses.

Now that we know this can happen as a byproduct of regression to the mean, let’s see if we can control for it in the real data. To do that, we will do a bootstrap test. We will shuffle the arc widths within participants many times, and find the expected distribution of likelihood ratios under the no-adaptation regression to the mean scenario. Then we can repeat our t-tests against this expected distribution instead of against 1.

Bootstrap test via shuffling trials

First, here’s how the results look after a single shuffling. Almost indistinguishable from the real deal.

exp1 |> 
  group_by(subject, experimentorder) |> 
  mutate(arc = sample(arc)) |> 
  calculate_expand_likelihood_ratio() |> 
  plot_likelihood_ratio()

Here is the bootstrap distribution for the mean likelihood ratios (corresponding to the red points in the plot above. The vertical lines represent the observed mean without the shuffling.

bootstrap_lr_shuffled_arcs <- function(dat) {
  dat |> 
    mutate(arc = sample(arc)) |> 
    calculate_expand_likelihood_ratio() |> 
    group_by(resp_type) |> 
    summarise(mean_ratio = mean(likelihood_ratio_expand))
}
out <- replicate(1000, bootstrap_lr_shuffled_arcs(group_by(exp1, subject, experimentorder)), simplify = FALSE)
out <- do.call(rbind, out)
observed_ratios <- smry1 |> 
  group_by(resp_type) |> 
  summarise(mean_ratio = mean(likelihood_ratio_expand))

out |> 
  ggplot(aes(mean_ratio)) +
  geom_histogram(bins = 60) +
  facet_wrap(~resp_type, scales = "free") +
  geom_vline(data = observed_ratios, aes(xintercept = mean_ratio), linetype = "dashed", color = "red") +
  ggtitle("Bootstrap distribution of mean likelihood ratios (after shuffling arcs)")

That is strange. In the real data participants contract less after hit and expand less after miss, than what would be predicted from regression to the mean. But the effect is in the opposite direction of what we would expect… If there was real contraction after hit and expansion after miss over and above the regression to the mean, they should have done more of it, not less, than predicted by regression only.

That doesn’t make any sense. Maybe some sort of Simpson’s paradox? Let’s get a separate bootstrap estimate for each subject under shuffling. Long plot coming:

bootstrap_lr_shuffled_arcs_by_subj <- function(dat) {
  dat |> 
    mutate(arc = sample(arc)) |> 
    calculate_expand_likelihood_ratio() |> 
    group_by(resp_type, subject, experimentorder) |> 
    summarise(mean_ratio = mean(likelihood_ratio_expand))
}
out <- replicate(1000, bootstrap_lr_shuffled_arcs_by_subj(group_by(exp1, subject, experimentorder)), simplify = FALSE)
out <- do.call(rbind, out)

out |> 
  mutate(subj_exp = glue::glue("S{subject}_E{experimentorder}")) |> 
  ggplot(aes(mean_ratio)) +
  geom_histogram(bins = 60) +
  facet_grid(subj_exp~resp_type, scales = "free") +
  geom_vline(data = mutate(smry1, subj_exp = glue::glue("S{subject}_E{experimentorder}")), aes(xintercept = likelihood_ratio_expand), linetype = "dashed", color = "red") +
  ggtitle("Bootstrap distribution of mean likelihood ratios (after shuffling arcs)")

It’s not a Simpson’s paradox. While there are many subject whose likelihood ratios are as expected under random suffling, there is a subset that consistently deviates in the wrong direction (as explained above). I compared this to the overall performance per subject here, and there doesn’t seem to be any obvious relation.

Let’s summarize this by calculating for each subject the percentile of their observed likelihood ratio for expansion relative to the shuffled bootstrap estimates.

boot_percentiles <- out |> 
  left_join(smry1, by = c("resp_type", "subject", "experimentorder")) |> 
  group_by(subject, resp_type, experimentorder) |> 
  summarize(percentile = ecdf(mean_ratio)(unique(likelihood_ratio_expand)))

boot_percentiles |> 
  ggplot(aes(resp_type, percentile)) +
  geom_violin(bw = 0.03) +
  geom_point(position = position_jitter(0.1), alpha = 0.4)

We can get a joint score by multiplying the percentile ranks of hit * (1-miss). Values close to 1 means that participants have the weird data where they deviate in the wrong direction from the shuffled expectations. We seem to indeed have two types of participants - about a quarter deviate strongly (percentile rank >= 0.99)

boot_percentiles |> 
  spread(resp_type, percentile) |> 
  mutate(joint = hit * (1-miss)) |> 
  ggplot(aes(joint)) +
  geom_histogram(bins = 100)
boot_percentiles |> 
  spread(resp_type, percentile) |>

Simulated adaptive algorithm and compare to bootstrap

Maybe my intuition is incorrect, and this is what we expect with the adaptation algorithm? Let’s see the expected data for a simulated agent using our algorithm 4 / 5. We will compare their expansion likelihood ratio when using the adaptation vs shuffled bootstrap.

sim_algo4 <- algo4(delta = 0.01) |> run_arc_algorithm(n_trials = 1000, init_arc = 1)
sim_algo4 <- data.frame(resperr = sim_algo4$y, arc = sim_algo4$a * 2)
sim_algo5 <- algo5() |> run_arc_algorithm(n_trials = 1000)
sim_algo5 <- data.frame(resperr = sim_algo5$y, arc = sim_algo5$a * 2)

Under algorithm 4 by design the agent never expands after a hit and never contracts after a miss.

sim_algo4 |> 
  calculate_expand_likelihood_ratio()
# A tibble: 2 × 4
  resp_type contracting expanding likelihood_ratio_expand
  <chr>           <dbl>     <dbl>                   <dbl>
1 hit                 1         0                       0
2 miss                0         1                     Inf

Algorithm 5 occasionally expands after a hit and contracts after a miss but very rarely and much less than in the human data.

sim_algo5 |> 
  calculate_expand_likelihood_ratio()
# A tibble: 2 × 4
  resp_type contracting expanding likelihood_ratio_expand
  <chr>           <dbl>     <dbl>                   <dbl>
1 hit             0.894     0.106                   0.118
2 miss            0.188     0.812                   4.33 
out <- replicate(1000, bootstrap_lr_shuffled_arcs(sim_algo5), simplify = FALSE)
out <- do.call(rbind, out)

Here is the result. The figure shows the expected likelihood ratio for expanding the arc for the simulated data from algorithm 5 when shuffling the arcs.

out |> 
  mutate(likelihood_ratio_expand = mean_ratio) |> 
  plot_likelihood_ratio()

The regression to the mean effect is real here too, and of the same magnitude, but it accounts for a very minor proportion of contractions after hits. After misses the algorithm LLR for expansion is 1.10185, which is smaller than 68% of the shuffled LLRs.

Normally this would indicate that the expansion isn’t due to adaptation but due to regression to the mean. However, in this case we know the ground truth - the algorithm does expand after misses! See section Visualizing algorithm 5 of the reinforcement learning notebook. It only does that after narrow misses, so that’s why the likelihood ratio for expansion is small. In this case, even though the effect size is consistent with what is expected under regression to the mean, we know there is no regression to the mean because the arc size is determined deterministically.

This finding means that shuffling the arcs is not necessarily a good control, and depends on the assumptions we put in (that the arc is a random sample from a distribution).
