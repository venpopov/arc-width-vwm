Arc width and continuous reproduction

Project overview

In the standard continuous reproduction paradigm, participants study a visual feature (e.g., a color) and later reproduce it on a continuous scale (e.g., a color wheel). The angular error between the response and the target is taken as a measure of memory precision — but a single trial’s error is just a sample from a distribution, not a direct measure of that trial’s memory quality.

In the uncertainty estimation procedure, participants additionally draw a symmetric arc around their point response, indicating the range of plausible values consistent with their memory. Participants are incentivized to set the arc wisely: points are awarded as

\[ p = (\pi - \alpha) \cdot \mathbf{1}[|y| \le \alpha], \]

where \(y\) is the signed response error and \(\alpha\) is the half-width of the arc. Wider arcs are safer (more likely to capture the target) but earn fewer points, creating an accuracy–confidence tradeoff.

This website documents analyses, simulations, and model-fitting results.

Datasets

  • Experiment 1 — 20 participants, manipulating set size (1–8 items) and encoding time / retention interval across two sessions.
  • Honig et al. (2020) — 12 participants, set size 4, ~1200 trials across four sessions.

Guide to the notebooks

The sidebar groups notebooks into three sections. Here is the recommended reading order:

Data Exploration

  1. Exp 1: Exploratory Analysis — Effects of set size, encoding time, and retention interval on point response error and arc width. Fits two-component mixture models and shows that arc width is affected by the same manipulations as response error.
  2. Exp 1: By-Subject Diagnostics — Per-subject distributions of response error and arc width to inspect individual differences and outliers.
  3. Honig et al.: Data Exploration — Preliminary exploration of the Honig et al. dataset.

Theory & Modeling

  1. Optimal Arc Width (SDM) — Derives the theoretically optimal arc width for any given memory error distribution. Fits the Signal Detection Model (SDM) and shows that empirical arc widths are remarkably close to optimal. Key notebook.
  2. RL Algorithms: Exploration — Develops and simulates five reinforcement learning algorithms (algo1–5) for trial-by-trial arc-width adaptation, progressing from simple heuristics to a noisy stochastic-gradient model. Key notebook.
  3. Model Fitting: MLE & Recovery — Implements maximum-likelihood estimation for the noisy-gradient model (algo5), validates identifiability via 10,000-iteration parameter recovery.

Empirical Tests

  1. Sequential Dependencies — Tests whether participants actually adapt arc width after hits/misses, as predicted by the RL models. Controls for regression to the mean via bootstrap shuffling.

Key concepts

  • SDM (Signal Discrimination Model) — A model of memory where recall errors follow a distribution parameterized by memory strength \(c\) and precision \(\kappa\).
  • Arc width — The confidence interval participants set around their response; \(\alpha\) is the half-width in radians.
  • Algorithms 1–5 — A progression of reinforcement learning update rules, from simple multiplicative adjustments to a stochastic gradient ascent model operating on logit-transformed arcs.
